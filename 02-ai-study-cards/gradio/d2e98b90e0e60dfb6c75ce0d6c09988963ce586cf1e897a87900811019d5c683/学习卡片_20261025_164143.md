### 🃏 问答卡 · 入门

> 介绍 Python 的基本概念：它是一门编程语言，用来写代码、编程序，让计算机完成任务。

---

**1. 问：** Python 是什么？

**答：** Python 是一门编程语言，用来编写程序、让计算机完成各种任务。

*💡 提示：看到 Python，先想到“编程语言”四个字。*

---

**2. 问：** 用 Python 写出来的内容叫什么？

**答：** 叫代码；把代码组织起来去完成一个任务，就是程序。

*💡 提示：写 Python 就是在写代码，代码组成程序。*

---

**3. 问：** Python 的作用是什么？

**答：** 用来编程：把人的想法写成计算机能执行的指令，从而完成任务。

*💡 提示：可以把 Python 理解成人和计算机沟通的语言。*

---

**4. 问：** 刚接触 Python，入门阶段应重点掌握什么？

**答：** 先弄清基本概念和定义：Python 是编程语言、它能做什么，再逐步学习动手写代码。

*💡 提示：先懂概念，再练代码。*

---

### ✏️ 填空题 · 入门

> 这份材料围绕 Python 这门编程语言，介绍其基本概念和最基础的入门知识。

---

**1. 题干：** Python 是一种 ____ 语言，语法简洁易读，非常适合初学者入门学习。

**答案：** 编程

*💡 提示：记住：Python 首先是一门编程语言。*

---

**2. 题干：** 在 Python 中，代码块不使用大括号，而是通过 ____ 来表示代码的层级关系。

**答案：** 缩进

*💡 提示：Python 靠缩进区分代码块，这是它的特色。*

---

**3. 题干：** 在 Python 中，把内容输出到屏幕上最常用的内置函数是 ____()。

**答案：** print

*💡 提示：print 就是“打印”到屏幕的意思。*

---

**4. 题干：** Python 编写的程序通常保存在扩展名为 ____ 的文件中。

**答案：** .py

*💡 提示：Python 的名字缩写就是 .py。*
